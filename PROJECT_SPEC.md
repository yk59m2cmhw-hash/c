# PROJECT_SPEC — Second Life (рабочее название)

**Трек:** AI + Climate (сокращение отходов). **Своя идея** (раздел 4.3.4 brief), не suggested project.
**Старт:** 16.11.2026, 02:00 по Алматы. **Дедлайн:** 09:59 по Алматы. **Точка решения:** 06:00 — если к этому времени нет работающего приложения с измеренным результатом, остаётся прежняя заявка (ветка `claude/keen-bohr-rsb2xk`).
Прежнее содержимое этой ветки (вариант «Smog Tomorrow», ревью и видео для keen-bohr) сохранено в истории: коммит `975aa99`.

**Формула:** помогаем школьнику дома решить, что делать со сломанной вещью — починить, переделать во что-то полезное или безопасно выбросить — по одной фотографии.

## Основной сценарий
Фото сломанной вещи (и по желанию одна строка «что сломано») → карточка: что это и что сломано; вердикт (починить / переделать / сдать или выбросить безопасно); лучшая идея с шагами; что понадобится из того, что есть дома; предупреждение об опасности; чего не делать.

Готово, когда:
1. Фото на входе даёт карточку на выходе настоящим вызовом модели.
2. Есть свой набор из ~30 фото настоящих сломанных вещей с человеческим описанием.
3. Наша схема и baseline оценены на тестовых фото, которые не использовались при настройке; оценки ставит человек вслепую.
4. Показан минимум один настоящий провал.
5. README по шаблону организаторов, ноутбук с сохранёнными выводами, видео до 2 минут.

## Объём
- **P0:** модуль с двумя шагами → baseline → тестовый набор → слепая оценка → результаты → ноутбук, демо (Gradio), README, видео.
- **P1:** нет.
- **Не входит:** аккаунты, база идей, поиск мастерских, расчёт CO2 (нет честных данных), мобильное приложение, дообучение.

## Что делает ИИ и что наше
- Модель с «зрением» (Gemini, бесплатный API) распознаёт вещь и поломку и пишет план. Без ИИ продукта нет: список советов не видит вещь.
- **Наше поверх готовой модели:** (1) два шага вместо одного: «осмотр» → правила безопасности в коде → «план»; (2) правила безопасности: при опасных признаках (литиевый аккумулятор, сеть 220 В, осколки стекла, лезвия, баллоны под давлением, химия и лекарства, плесень) код запрещает советы «вскрыть и починить» и требует предупреждение; (3) идеи только из домашних материалов и инструментов по списку; (4) свой тестовый набор фото и слепая оценка.

## Протокол оценки (фиксируется этим коммитом, до любого запуска на тестовых фото)
- **Данные:** ~30 своих фото. Участник пишет для каждого: что это и что сломано. По этому описанию (не по ответу модели) каждой вещи ставится метка «опасно разбирать самому: да/нет» по списку признаков выше.
- **Разбиение:** фото сортируются по имени файла; каждое четвёртое (1-е, 5-е, 9-е…) идёт в development, остальные в test. Настройка промптов — только на development. После заморозки промптов (отдельный коммит) test запускается один раз.
- **Baseline:** та же модель, то же фото, один запрос с той же схемой карточки и той же просьбой учесть безопасность. Никаких правил в коде.
- **Метрики на test** (считаем штуками, не только процентами):
  1. Вещь распознана верно (да/нет) — сверка с описанием участника.
  2. Безопасность: из опасных вещей — на скольких есть ясное предупреждение и нет совета вскрывать; из неопасных — на скольких лишнее предупреждение.
  3. Полезность лучшей идеи, три вопроса «да/нет»: смогу ли сделать это дома из перечисленного; полезен ли результат; подходит ли идея именно к этой вещи и поломке. «Годная идея» = три «да».
- **Слепая оценка:** участник видит две карточки на вещь в случайном порядке и не знает, какая чья. Оценивает по-русски.
- **Что публикуем:** любой исход. Если два шага не лучше одного запроса — так и пишем и оставляем более простой вариант.
- **Ограничения, о которых скажем сами:** один оценщик (автор); ~22 тестовых фото; вещи из одного дома; оценка «смог бы сделать» — мнение, а не проверка делом.

## Риски и запасные действия
| Риск | Признак | Действие |
|---|---|---|
| Лимиты бесплатного API | ошибки 429 | пауза между вызовами; меньше тестовых фото |
| Модель недоступна | ошибки 4xx/5xx по всем моделям | другой бесплатный сервис; если нет к 03:30 — остаётся прежняя заявка |
| Мало фото | меньше 20 | честно сузить выводы |
| Нет времени на оценку | к 05:30 оценок нет | остаётся прежняя заявка |
