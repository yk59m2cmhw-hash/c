## Подтверждённые метрики (тест 11.10.2024 – 13.11.2025: 396 дней, 216 в октябре–марте, 88 плохих)
| Прогноз | MAE окт–март | MAE все дни |
|---|---|---|
| «Завтра как последние 24 ч» | 17,0 | 10,9 |
| «Завтра как полные сутки сегодня» | 15,3 | 9,9 |
| Типичное для месяца | 18,5 | 11,7 |
| **Модель (Ridge)** | **12,2** | **8,2** |

- Выигрыш над persistence: 4,8 µg/m³ в день (95 % интервал 3,0–7,0).
- Тревога: модель 72 поймано / 16 пропущено / 22 ложных; persistence с подобранным порогом 69 / 19 / 40.
- Начало смога (31 день): модель предупредила о 17, persistence о 12.
- На реальных прогнозах погоды («за день до» и «за два дня до»): MAE 12,2 и 12,1.
- Диапазон накрыл 76 % дней (строился на 80 %).
- Расписание (29 недель, 2 урока): фиксированное 40,0; правило + persistence 37,5; правило + модель 35,4; идеальный выбор 26,7. Против простого планировщика выигрыш не доказан (2,1; интервал −1,3…5,9).

## Принятые решения
1. Прогноз в 18:00; цель — среднее следующих календарных суток; split по датам.
2. Модель Ridge: бустинг и сигнал инверсии не дали выигрыша на двух прошлых зимах.
3. Тест прогноза — один запуск (15.11, 08:38 UTC). Раздел «расписание» добавлен после, правило без подгонки.
4. Код — отдельная ветка `claude/breathing-timetable` в `yk59m2cmhw-hash/c`. Ветку другой сессии (`claude/relaxed-dirac-2g7xn0`) не трогаем.
